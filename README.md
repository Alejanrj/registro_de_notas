# Registro de Notas - M1

Este es un proyecto de consola desarrollado en Python como parte del módulo de Desarrollo de Software. La aplicación permite gestionar el ingreso de estudiantes y sus respectivas notas mediante un menú interactivo.

## 🚀 Funcionalidades
* **Registrar ingreso:** Permite guardar el nombre de un estudiante en el sistema.
* **Registrar nota:** Busca a un estudiante por su nombre y le asigna una calificación.
* **Ver promedio:** Calcula y muestra el promedio general de todos los estudiantes registrados.
* **Salir:** Finaliza la ejecución del programa.

## 🛠️ Tecnologías utilizadas
* **Python 3.x**
* **Git y GitHub** (Control de versiones)
* **Diccionarios y Listas** para la gestión de datos.
